# 추가 입력의 정확한 정의와 처리 근거

이 문서는 2024년 11월 원천의 전수 검수와 첫 입력 배열 준비 뒤, 추가 자료를 사용한 모델 학습 전에 정리한다. 2025년 성능을 보고 정한 특징이나 사전 등록된 독립 시험으로 제시하지 않는다. 기존 준비계획의 자료 선택·시점·집계·누락·ID 규칙을 구체화한다.

## 버스정류소 정적 특징 4개

최근접 정류소까지의 직선거리(m), 300m·500m·1000m 안의 정류소 수를 그대로 사용한다. 임의 표준화·극값 제거를 수행하지 않는다. 거리와 개수는 접근성의 다른 측면을 나타내므로 한 값으로 합치지 않는다. 도보 경로나 노선 수·배차·승객 수로 해석하지 않는다. 원본 좌표의 포털 설명과 실제 경도·위도 값의 불일치를 확인한 기존 검수를 유지한다.

## 선행 흐름 특징 7개

같은 ST-ID·요일·시각에 행이 나타난 날짜들의 출발 또는 도착 건수를 합산하고, 해당 날짜 수로 나눈다. 관측된 날짜당 평균의 `log(1+평균)` 두 개, 출발·도착 수록 일수 비율 두 개, 출발·도착 기록 존재 마스크 두 개, 현재 교차표 연결 마스크 한 개로 구성한다.

로그 변환은 음이 아닌 건수의 순서를 유지하고 큰 규모의 수치를 압축하는 고정 표현으로 사용한다. 학습·검증 전체에서 구한 평균·표준편차로 정규화하지 않는다. LightGBM에서는 단조 변환만으로 추가 정보가 생기지 않으므로 로그 자체가 성능을 높이는 기법이라고 주장하지 않는다. 향후 신경망 등과 입력 표현을 공유하기 위한 구현 선택으로 구분한다. [LightGBM의 공식 트리 학습 설명](https://lightgbm.readthedocs.io/en/stable/Features.html)을 참고하며 원본 평균도 정제본에 함께 보존한다.

수록 일수 비율은 같은 요일의 비어 있지 않은 일파일 수를 분모로 사용한다. 달력 날짜와 그에 대한 비율도 원본 프로필에 진단용으로 남긴다. 전체 파일이 비어 있는 11월 27일은 노출 분모에서 제외한다. 특정 대여소·시각에 행이 없으면 평균은 결측으로 유지하고, 알려진 수록 일수 0과 기록 존재 마스크 0으로 표현한다. 실제 이동 0을 관측한 것으로 바꾸지 않는다. 현재 교차표가 연결되지 않은 대여소는 흐름 수치·수록률·기록 마스크를 모두 결측으로 두고 연결 마스크만 0으로 표시한다.

## 입력 시각과 달력 연결

예측 입력 t의 한 시간 뒤인 t+1의 요일·시각 프로필을 조회한다. 다음 시간의 달력은 알 수 있지만 실제 미래 대여·반납은 알 수 없으므로 2024-11로 고정한 프로필만 참조한다. 일요일 23시→월요일 0시, 입력 순서·중복 인덱스, 미연결 결측 보존을 검사한다.

표시 수정일 다음날이라는 보수적 날짜 대리 기준으로 OD는 2024-12-09, 버스정류소는 2024-12-11 이전 입력에 값을 제공하지 않는다. 판정 기준은 **입력 t**이며 미래 정답 시각을 이용해 공개 전 값을 허용하지 않는다. 이 규칙은 실제 최초 발표·수신 시각을 확인한 것과 다르다. 역사 수정·수신·ST-ID 동일성 미검증이 남아 있으므로 모든 추가 비교를 조건부 자료 비교로 표시한다.

## 후속 비교의 해석

같은 105개 공간·전환 특징 LightGBM에 버스 4개, 흐름 7개, 둘을 합친 11개를 각각 더하는 세 후보를 A/B/C에 비교한다. 순서는 버스→흐름→결합으로 정한다. 학습 기간·모형 설정·종료·확률 보정·정책 선택·검증 분모를 그대로 유지해 추가 정보의 차이를 확인한다. 이미 확인한 개발 기간의 추가 탐색으로 구분하며 운영 성능이나 독립 최종 시험 우위로 바꾸어 쓰지 않는다.
