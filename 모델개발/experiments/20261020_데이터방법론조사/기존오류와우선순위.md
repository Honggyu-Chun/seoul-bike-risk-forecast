# 기존 오류에서 정한 실험 우선순위

근거는 이미 열린 `artifacts/improvement/final/results.json`의 고정 결과이다. 새 모델·예측·시험 점수를 만들지 않고, 기존 혼동행렬과 보조 구간의 관계만 계산한다. 계산 근거는 `existing_error_analysis.json`에 남긴다.

## 놓치는 위험이 어디에 있는지 확인한다

| 기존 M2의 오류 구간 | 놓친 0대 위험 | 전체 놓침에서의 비중 |
| --- | ---: | ---: |
| 전체 | 48,187건 | 100.00% |
| 현재 양수 → 다음 0대 | 43,631건 | 90.55% |
| 현재 1~3대 → 다음 0대 | 37,799건 | 78.44% |

1~3대 구간은 현재 양수 구간에 포함되므로 두 행을 합하지 않는다. 현재 양수에서 다음 0대가 된 실제 사례 51,237건 중 45,025건, 약 87.88%는 현재 1~3대 구간이다.

이 분포는 **다음 시간에 새로 비는 대여소를 찾는 능력**이 중요한 개선 과제임을 보여준다. 현재 이미 0대인 상태를 잘 유지 예측하는 것만으로는 시민이 비교할 현재 양수 후보의 위험을 충분히 설명하지 못한다. 다만 전체 F1을 버리고 부분집합 점수만 최대화하는 방식은 기존 주목적을 바꾸므로 채택하지 않는다.

## 가장 먼저 검토할 세 가지 묶음

**1. 기간·계절·재학습 방식부터 넓힌다.** 현재 사용된 겨울~봄 이력 외에 확보한 2024년 자료와 2025년 5월 이후 자료를 연결할 수 있다. 최근 56·112일 창, 전년도 요약, 주간 재학습을 기존 M2와 같은 조건에서 비교한다. 단순히 원본 행 수를 늘리는 것보다 계절 변화와 현재 패턴 사이의 균형을 확인한다.

**2. 줄어드는 이유를 설명할 정보를 보완한다.** 같은 현재 수량 2대라도 유입·유출, 시간·휴일, 주변 흐름, 비·바람 변화에 따라 위험이 다를 수 있다는 가설을 검토한다. 단순 증감·주변 평균·과거 전환율은 이미 구현돼 있으므로, 새로운 OD·예보·지역 기상을 추가할 수 있는지와 당시 제공 가능성을 먼저 확인한다.

**3. 트리와 다른 오류를 만드는 학습 구조를 비교한다.** 입력이 제한된 기존 신경망 비교를 보완할 긴 입력 STID·TCN, 수량 변화와의 공동 학습, TabM, 실제 희소 그래프 모델을 차례로 검토한다. 새 모델이 단독으로 이기지 못하더라도 다른 오류를 줄인다면 시간 외부 예측에 기초한 결합을 검토한다.

세 묶음의 우선순위는 기존 오류와 정보의 공백에 근거한 판단이다. 그 자체가 향상을 입증하지는 않는다. 실험 실행을 요청받은 뒤 후속 검증 계획으로 검증해야 한다.

## 지표를 함께 판단한다

- 현재 양수 구간에서 기존 M2의 재현율은 14.8447%이며 오경보는 7,814건이다. 재현율만 높이고 오경보가 크게 늘면 시민의 불필요한 이동을 늘릴 수 있다.
- 전체 F1, 전환 구간의 AP·정밀도·재현율과 확률 품질을 함께 확인한다. 최종 목표와 보조 진단을 구분한다.
- 수량 기준·임계값을 바꾸는 효과와 모델의 판별력이 높아지는 효과를 분리한다.
- 기대효과의 배수나 +%p를 조사 단계에서 미리 약속하지 않는다. 실제 개선 폭은 실행 이후의 새 시험에서 확인한다.
