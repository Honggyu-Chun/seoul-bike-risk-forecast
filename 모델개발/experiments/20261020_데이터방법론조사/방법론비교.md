# 방법론 비교와 우선순위

이 문서는 48개의 **모델·특징·학습·검증 검토 항목**을 구분한다. 48개 독립 모델을 새로 실험한 결과로 표현하지 않는다. 기존 45개 1차·15개 후속 후보의 실제 목록은 `existing_candidates.csv`에서 확인한다.

상태는 `기존`(이미 실험), `확장`(기존 방법을 새로운 조건에서 비교), `신규`(현재 기록에서 구현·실험을 확인하지 못함), `조건부`(자료·과제·자원 조건이 선행)로 표시한다. `신규`는 학술적으로 새로운 알고리즘이라는 뜻으로 사용하지 않는다. P0부터 P3까지의 우선순위는 조사자의 판단이며 성능 향상 확률을 측정한 값은 아니다.

## 1. 기준 모델과 강한 대조군

자전거 예측 문헌에는 RF·부스팅·선형·ARIMA·Prophet 등이 사용된다. 단일 모델이 모든 도시에서 우세하지 않은 비교도 있다. 따라서 이 과제에서 일반적으로 쓰이는 방법을 대표하는 RF·GBDT를 핵심 기준으로 삼고, 기존 B1과 M2를 함께 유지한다. 수량 회귀 논문의 오차를 0대 분류 F1의 근거로 바꾸지 않는다. [수량 예측 연구](https://arxiv.org/abs/2006.08352), [도시간 비교 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC10556600/)

| --- | --- | --- | --- |
| M01 | 현재 상태 유지 | 기존·P0 | 현재 0대를 다음 0대로 예측하는 규칙을 유지해 학습 모델의 기본 이익을 확인한다. |

| M03 | 로지스틱 회귀 | 기존·P1 | 단순한 확률 모델과 비용을 비교한다. 현재 선형 후보가 있음을 확인한다. |

| M08 | 자기 대여소 입력과 공간 입력의 짝비교 | 확장·P0 | 학습기 변경 효과와 추가 정보 효과를 분리한다. 공간 집계 특징은 이미 사용함을 명시한다. |

## 3. 목표와 확률 모형

수량 회귀 오차를 낮추는 것과 정확히 다음 격자에서 0대가 되는 위험을 잘 분류하는 것은 다른 목표다. 기존 Poisson·하위 분위수 후보는 수량 예측을 위험 점수로 변환한다. 새 분포 모형은 명시적인 `P(Q_next=0)`를 산출하고 이진 분류 기준과 비교해야 한다. [분포 회귀의 공식 지원 목록](https://statmixedml.github.io/XGBoostLSS/distributions/)

| ID | 검토 항목 | 상태·우선 | 개선 가설과 제약 |
| --- | --- | --- | --- |
| M21 | 양수·0대 상태별 전문가 | 기존·P1 | 이미 두 전문가를 실제 학습한다. 상태를 나누는 것 자체를 새 제안으로 주장하지 않는다. |
| M22 | 직접 위험 분류와 순수량 변화의 공동 학습 | 신규·P1 | 0대 위험·감소 크기를 함께 학습해 표현을 보완한다. 보조 손실이 주목적을 해치는지 비교한다. |
| M23 | 순서형 수량 구간 예측 | 신규·P1 | 0·1·2·3대 이상을 구분해 저수량 경계를 학습한다. 최종 0대 확률의 품질을 다시 평가한다. |
| M24 | Negative Binomial 분포 회귀 | 신규·P1 | 분산을 평균과 별도로 학습해 과산포를 설명한다. 분포 부적합과 수량 상한 문제를 검수한다. |

| M27 | 과거 전환율의 계층 평활·상태 지속 | 기존·P1 | 전역·대여소·시간·요일·지속·최근 전환 통계를 이미 사용한다. 새 지역/기상 조건은 추가 효과를 따로 확인한다. |

| M30 | 보정·임계값 선택 | 기존·P0 | 확률과 의사결정의 조정을 유지한다. 임계값 변경만으로 판별력이 개선됐다고 주장하지 않는다. |

출생사망과정 연구의 최초 고갈 시각이나 시간 구간 중 고갈 확률은 현재 정답과 다르다. 현재 정답은 다음 정각의 수량이 0인지이며, 중간에 비었다가 채워진 경우를 별도로 알 수 없다. [점유 과정 원논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC5856052/)

## 실제 추진 순서에 대한 판단

1. 수량 원본의 기간·스키마·제공 시점을 확인하고 일반적인 기준과 기존 M2를 같은 새 분할에 놓는다.
2. 56·112일 학습 창, 실제 주간 갱신, 전년도 요약, 공휴일을 먼저 비교한다. 기존 최근성 가중치와의 중복을 기록한다.
3. 제공 시점이 확인되는 과거 OD·예보·국지 기상을 차례로 추가한다. 확인되지 않으면 아카이브 보조 실험으로 제한한다.
4. 더 긴 입력의 STID·TCN, 순서형·공동 학습, TabM을 서로 다른 오류를 만드는 후보로 비교한다.
5. 희소 그래프 후보를 비교하고 유효한 차이가 남을 때 시간 스태킹과 조건별 결합을 검토한다.
6. 기반 모델과 대형 주의집중 모델은 선행 비교에서 남는 오류와 계산 비용이 정당화할 때 진행한다.

공휴일·OD·그래프·사전학습이라는 이름만으로 성능을 보장하지 않는다. 새로운 입력이 없고 같은 손실·자료를 반복하면 복잡한 모델도 기존 트리보다 못할 수 있다. 각 가설의 채택은 후속 검증 계획의 비교 결과로 결정한다.
