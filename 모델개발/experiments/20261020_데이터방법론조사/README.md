## 이번에 확인한 사실

- 현재 패널 생성 코드는 2025년 5월 14일까지만 사용한다. 기존에 사용한 2분기 ZIP에는 6월 파일도 들어 있다.
- 공식 OA-22382에서 2024년 1~4분기와 2025년 3~4분기 ZIP 6개를 실제 확보하고 SHA-256 및 ZIP CRC를 확인한다. 파일 목록상 18개월에 해당하며 관측 누락과 실제 행 단위 범위는 아직 검수하지 않는다.
- 새 ZIP의 개별 수량, 0대 비율, 모델 점수는 계산하지 않는다. 18개 월별 CSV의 헤더가 `일시·대여소번호·대여소명·시간대·거치대수량`임을 확인하며 파일 존재·압축 검증과 정답 평가를 구분한다.
- 기존 연구는 45개 1차 후보와 15개 후속 후보를 비교한다. 수량 상태별 전문가, 최근성 가중치, Markov, 계절 시차, 다중 반경 주변 특징, Focal, 소형 신경망도 이미 포함한다.
- 기존 신경망은 24시간·4채널과 최대 8에포크를 사용한다. 트리에는 장기 시차가 있으나 신경망에는 동일한 입력이 들어가지 않는다. 기존 신경망 비교는 전체 신경망 계열의 가능성을 소진한 실험으로 해석하지 않는다.
- 이 PC는 i7-1195G7, 물리 4코어·논리 8스레드, RAM 약 15.7GiB와 Intel Iris Xe를 사용한다. CUDA GPU를 확인하지 못한다. 기존 32GiB 연구 예산을 그대로 적용하지 않는다.

## 현재 성능의 기준점

아래 수치는 `artifacts/improvement/final/results.json`과 기존 보고서에 기록된 **이미 열린 2025-04-15~05-14 시험 결과**를 인용한다. 이번 조사에서 다시 학습하거나 재평가하지 않는다.

| 지표 | 기본 B1 | 기존 최종 M2 | 해석 |
| --- | ---: | ---: | --- |
| 전체 0대 분류 F1 | 72.9593% | 74.0702% | +1.1109%p로 기존 +5%p 목표에 미달한다. |
| 현재 양수 구간의 0대 전환 재현율 | 6.9832% | 14.8447% | 약 2.1배이나 전환의 약 85.2%를 여전히 놓친다. |
| 같은 구간 오경보 | 3,964건 | 7,814건 | 전환 탐지 증가와 함께 오경보도 증가한다. |

기존 M2는 LightGBM의 시공간·과거 기상 확률과 CatBoost 확률을 50:50으로 결합한다. 새 모델은 B1뿐 아니라 **동일 기간에 다시 학습한 M2와 충분히 조정한 트리 모델**을 넘어서는지 확인해야 한다.

## 진행 범위

사용자는 범위를 “이번에는 조사와 실험 설계까지만 진행”으로 확정한다. 이에 따라 자료 조사, 공개 원본 확보, 기존 결과 대조와 후속 실험 설계까지 수행한다. 서비스 기능 개발, 모델 구현·학습, 새 성능 평가는 수행하지 않는다. 조사 자동화 코드는 공개 자료 다운로드와 기록 작성만 수행한다.

실제 성능 개선과 개선 후보의 실험적 소진은 이번 결과에 포함하지 않는다. 향후 사용자가 실험을 요청할 때 이 설계를 출발점으로 사용한다.
