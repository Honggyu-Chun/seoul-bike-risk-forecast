# 후속 모델 실험 기록

새 실험을 시작하기 전에 이 폴더에 실험별 기록을 만든다. 기존 고정 시험 결과와 새 실험의 목적 및 출력 경로를 구분한다.

## 실험 이름과 저장 위치

실험 기록은 `YYYYMMDD_실험이름.md` 형식으로 작성한다. 새 예측과 모델 파일은 기존 `artifacts/improvement/final`을 덮어쓰지 않는 별도 실행 폴더에 저장한다. 데이터와 모델의 전체 경로보다 프로젝트 루트에 대한 상대 경로를 기록한다.

## 기록할 내용

- 해결할 문제와 바꿀 특징 또는 모델을 기록한다.
- 학습, 선택, 시험에 사용할 기간과 기존 시험의 재사용 여부를 기록한다.
- 데이터 버전, 설정 파일, 코드 변경, 임계값과 모델 결합 조건을 기록한다.
- 기본 모델과 제안 모델을 같은 조건에서 비교한 수치와 실행 시간을 기록한다.
- 전체 성능과 현재 양수에서 다음 0대로 바뀌는 구간의 성능을 구분한다.
- 성능이 좋아진 경우와 나빠진 경우를 함께 검토하고 채택 여부를 기록한다.
- 결과 파일 경로와 제안서에 반영할 주장을 연결한다.

## 현재 기준을 확인하는 자료

현재 실험 조건은 `../config/improvement_v3.json`, 방법 조사와 설계는 `../reports/method_search/research_design.md`, 기존 비교 결과는 `../reports/improvement_results.md`에서 확인한다. 기존 최종 결과는 `../artifacts/improvement/final/results.json`에서 확인한다.

## 추가 데이터·방법론 조사

[2026-10-20 조사와 후속 검증 설계](20261020_데이터방법론조사/README.md)에서 새로 확보한 수량 원본, 48개 검토 항목, 일반적인 기준 모델, 이후 기간 검증 설계를 확인한다. 사용자 요청에 따라 조사·설계까지만 수행하며 모델 구현·학습·새 성능 평가는 포함하지 않는다.

## 실제 모델 실험으로 확장

이후 사용자가 실제 학습·비교를 요청함에 따라 [후속 실제 실험 v4](20261020_후속실험_v4/README.md)에서 기준 모델과 추가 데이터·신경망 비교를 진행한다. 위 조사 기록의 당시 범위는 보존하고 현재 실행 결과는 새 폴더에 기록한다.

## 공공데이터 조사와 실제 입력 준비

[추가 공공데이터 통합보고서](20261020_공공데이터추가조사2/공공데이터_추가조사_통합보고서.html)는 교통·이동, 공간·시설, 인구·행사의 62개 후보와 공식 근거·제공 지연·인증 조건을 정리한다. 기존 원천 재검토와 부적합 후보도 포함한다.

[자료 준비 설명](20261020_추가공공데이터적용/데이터준비_쉬운설명.html)은 버스정류소 특징과 2024-11 대여·반납 흐름의 원본·정제·누락·ID 연결을 설명한다. [추가 자료 모델 비교](20261020_추가공공데이터적용/추가공공데이터_비교보고서.html)는 기존 v4 큐가 끝난 뒤 9개 추가 비교의 진행 상태와 실제 성과를 기록한다. 과거 수신·원본 불변·ID 동일성 미검증이 남은 자료는 조건부 비교로 표시한다.

v4 결과는 `../artifacts/followup_v4_20261020`, 추가 입력 배열은 `../artifacts/followup_public_features_20261020`, 추가 모델·예측은 `../artifacts/followup_public_20261020`에 저장한다. 재개 전 실제 학습과 대기 큐가 살아 있는지 확인하고 한 번에 하나만 학습한다.
