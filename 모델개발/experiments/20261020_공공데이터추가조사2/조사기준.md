# 영향을 줄 수 있는 공공데이터의 추가 탐색

사용자의 2026-10-20 추가 요청에 따라 세 조사 작업을 병렬로 수행한다. 교통 흐름, 공간·시설, 인구·행사로 담당 범위를 나누고 기존 연구와 대조한다. 이미 확보한 API의 여러 필드를 서로 독립적인 새 원천으로 부풀리지 않는다.

## 넓게 찾되 사용 조건을 구분한다

- 따릉이의 출발 수요·반납 공급·다른 교통수단과의 대체·대여소 접근 가능성·도착 시간에 영향을 줄 수 있는 가설을 수집한다.
- 실시간 수치, 미리 알려진 일정, 안정적인 공간 맥락, 지연 발표 통계를 구분한다. 실시간으로 새로 측정하지 않는 정보도 예측 전에 알려져 있으면 후보로 검토한다.
- 현재 접속 가능한 서비스, 2025년 과거 이력, 당시 발표·수정·수신 시각의 증거를 별도로 기록한다.
- 영향 가능성과 실제 성능 향상을 구분한다. 이 조사만으로 새로운 데이터의 효과를 입증했다고 표현하지 않는다.
- 원천의 정확한 명칭·공식 URL·분해능·스키마·접근 결과·키·승인·이용 조건·남은 작업을 남긴다.

## 적용 판정

| 판정 | 의미 | 다음 작업 |
| --- | --- | --- |
| 즉시 준비 가능 | 현재 인증 또는 무인증으로 확보할 수 있고 공간·시간 연결이 명확하다. | 작은 전체 자료나 샘플을 보존하고 시점 조건을 검사한다. |
| 추가 작업 필요 | 새 키·서비스 신청·승인·이력 수집이 필요하다. | 필요한 사이트와 구체적인 절차를 사용자에게 보고한다. |
| 조건부 | 현재 자료는 있으나 과거 버전·게시·수신 시점 또는 정의가 미확인이다. | 주 실시간 성과와 분리해 처리하고 확인 조건을 명시한다. |
| 부적합 | 예측 시점 이후의 실적이거나 공간·시간 해상도와 제공 조건이 맞지 않는다. | 제외 이유를 남기고 원천을 억지로 입력에 넣지 않는다. |

## 현재 실험과의 관계

후속실험 v4의 정답·기간·기준 모델·후보 선택 규칙을 보존한다. 등록된 CPU 학습을 중복 실행하지 않는다. 새 원천은 별도 자료·특징 준비 영역에서 검토하며, 추가 학습을 시작하기 전에 비교 대상·지연·시간 연결·효과 분리 규칙을 기록한다. 과거 3·4분기 미개봉 정답을 조사 과정에서 열지 않는다.

대용량 수집과 유료 신청은 이번 병렬 조사에서 수행하지 않는다. API 비밀값은 로컬 .env에서만 읽고 보고서·로그·요청 URL에 노출하지 않는다. 차단된 KOPIS에 반복 요청하거나 우회하지 않는다.
