# 데이터 처리 선택과 근거

최신 요청에 따라 처리 방법, 이유, 조사한 근거와 한계를 함께 기록한다. 논문에서 직접 검증한 방법과 프로젝트에서 보수적으로 정한 규칙을 구분한다. 이 기록은 이미 적용한 처리의 설명이며 모든 대안보다 우월함을 입증한 문서로 사용하지 않는다.

## 성능 차이의 날짜별 변동을 확인하는 이유

같은 날의 여러 대여소와 인접 시간이 서로 관련될 수 있으므로 개별 행을 독립적으로 다시 뽑아 과도하게 좁은 범위를 만들지 않는다. 한 날짜의 모든 대여소·시간을 하나로 묶고, 같은 날짜를 두 모델에 함께 적용하는 짝지은 재표집으로 정한다. 1일 묶음과 연속 7일 묶음의 차이를 함께 보며, 각 재표집에서 혼동행렬을 합한 뒤 F1·정밀도·재현율을 계산한다. 날짜별 F1 평균과 전체 F1을 혼동하지 않는다.

종속 자료에 블록 재표집을 사용하는 발상은 [Kuffner·Lee·Young의 원 논문 초록](https://arxiv.org/abs/1909.02662)을 참고한다. 이 논문은 밀도 추정에 대한 이론이므로 그 최적성 결과를 본 프로젝트의 분류 F1에 직접 옮기지 않는다. 원래 블록 연구의 서지는 [Künsch의 저자 논문 목록](https://people.math.ethz.ch/~kuensch/papers/)에서도 확인하며, 출판사 원문 페이지는 접근 제한으로 본문을 확인하지 못한다. 과거만 학습에 사용하는 시간 순서 검증은 [저자가 공개한 시계열 교차검증 설명](https://otexts.com/fpp3/tscv.html)을 별도 근거로 둔다.

블록 길이 1·7일, 2,000회, 초기값 20261020은 프로젝트의 탐색적 민감도 설정으로 정한다. 이미 일부 개발 성과를 본 뒤 추가한 보조 분석임을 `uncertainty_plan.json`에 명시한다. 14~17일의 짧은 기간·정상성 미검증·주간 묶음 수·끝부분 가중·다중 비교·단일 모델 초기값·학습 기간 중첩이 남는다. 2.5~97.5% 재표집 범위를 보장된 95% 신뢰수준이나 독립 시험의 우월성 증명으로 부르지 않는다. 결과 JSON의 전체 오류와 복원한 판정의 오류가 일치하는지 검사한 뒤 집계한다.

## 대기질 추가 비교의 처리 근거

현재 공식 API에서 확인한 6개 물질과 같은 의미·단위를 가진 과거 자료를 사용한다. 자치구별 센서값을 그 구의 대여소에 연결하며 개별 대여소 옆 센서라고 설명하지 않는다. 현재 25개 구 응답이 한 시간 전 관측을 전달한 사실을 근거로 2시간과 3시간 전 값을 별도 비교한다. 이 지연은 관측 1회의 여유 규칙이며 공급자의 보장된 최대 지연으로 사용하지 않는다.

각 물질의 수치와 자체 유효 플래그만 기준 모델에 추가한다. 높은 농도를 임의로 이상치 삭제하지 않고, 없는 값은 NaN으로 둔다. 2시간과 3시간 비교로 여유 시간 증가가 성능에 미치는 차이를 확인한다. 역사 자료에 실제 received_at이 없으므로 이 실험을 당시 수신 조건까지 재현한 것으로 제시하지 않는다. 운영에서는 수신 시각·관측 나이·결측 규칙을 별도로 적용하고 로컬 스냅샷을 축적해야 한다. 원본 표의 exact-shift 검사와 실시간 검증은 `추가데이터_병렬조사`에 보관한다.

학습과 운영의 특징 정의를 맞추기 위해 실제 모델 어댑터는 정확히 t-2h 또는 t-3h에 해당하는 관측만 선택한다. 일반 선택기의 기본 6시간 범위에서 더 오래된 값을 가져와 `lag2h`로 이름만 바꾸지 않는다. 정확한 관측이 없거나 t까지 수신하지 못했으면 결측으로 남긴다. 입력 시각도 학습과 같은 정시 격자로 제한해 17시15분 입력을 17시 정답 정의처럼 사용하지 않는다. 이 결정은 과거 특징과 운영 특징의 불일치를 막기 위한 것으로, `air_runtime.py`와 해당 검사에 남긴다.

## 디스크 읽기

기존 행 중심 행렬을 특징별로 반복 조회하면 큰 파일을 여러 번 건드릴 수 있다. 수치나 표본을 바꾸지 않고 5만 행씩 읽어 필요한 열을 복사하는 방법을 추가한다. 이는 통계적 성능 개선 가설이 아니라 I/O와 메모리 복사를 줄이는 구현 선택으로 둔다. 행 순서·중복 인덱스·열 순서·NaN 보존을 검사한다. 이전 완료 결과는 재학습하지 않고 새 실행에는 읽기 구현의 해시를 남긴다.

## 시간 신경망 입력

기존 짧은 입력만으로 신경망 계열 전체를 판단하지 않기 위해 24시간과 168시간을 비교한다. STID의 간결한 시간·대여소 식별자 기준을 참고하되 이 구현은 0대 분류에 맞춘 변형으로 기록한다. 수량에는 log1p, 수량 차이에는 부호를 유지한 log1p를 사용해 큰 수치가 학습을 지배하는 정도를 줄인다. 실제 큰 수량을 임의의 상한으로 삭제하지 않는다. 결측 수치는 계산용 0과 별도 관측 마스크를 함께 제공하므로 실제 0대와 구분한다. 이 변환은 고정 수식으로 적용하며 미래 분포로 스케일러를 적합하지 않는다.

거리 이웃 효과를 모델 크기 증가와 혼동하지 않기 위해 같은 그래프 헤드·인코더·초기값·학습 표본을 가진 자기 자신 연결 대조군도 추가한다. 5개 거리 이웃의 평균과 자기 자신만 연결한 경우를 비교하며, 단순 TCN과 그래프 TCN만 비교해 공간 정보만의 효과라고 주장하지 않는다.

## 과거에 생성된 기상 예보 추가 비교

다음 시간의 실제 날씨는 예측 시점에 알 수 없으므로 입력하지 않는다. 대신 이전 날 오프셋의 GFS 예보에서 유효 시각이 자전거 정답 시각 t+1인 5개 변수를 사용한다. 공급자가 반환한 격자와 가장 가까운 대여소를 연결하며 요청 좌표를 실제 격자 좌표로 오해하지 않는다. 이 자료는 대여소 현장 센서 관측이 아니다.

현재 공식 메타데이터에서는 모델 초기화부터 API 가용까지 약 5.74시간 차이를 확인한다. 이전 날 오프셋의 명목 시간 여유와 현재 수신 경로가 있어 조건부 실험 후보로 정한다. 그러나 현재 지연 한 번으로 2025년의 모든 실행 공개 시각을 보장하지 않는다. `fixed_lead_hours=24`라는 기존 정제 열은 요청 오프셋 이름으로 해석하며 행별 정확한 실행 시각으로 복원하지 않는다. 역사 공개·수신 검증 플래그를 False로 보존하고 주 운영 우세 모델 선정에서 제외한다. 공식 근거와 원 메타데이터는 `추가데이터_병렬조사/GFS_실시간적격성_최종검토.md`에 보관한다.

## 판정 사례를 같은 기준으로 고른다

전체 성능의 검수와 별개로 기본 모델과 결합 모델의 차이를 설명할 실제 관측 사례를 만든다. 결과를 확인한 뒤의 설명용 분석으로 구분한다. 현재 양수에서 기본 놓침→결합 포착, 그 반대, 기본 오경보→결합 정상, 그 반대, 두 모델 모두 놓침·모두 포착의 여섯 유형을 고정한다. 각 유형에서 시간 순서와 고정 코호트 순서의 첫 행을 고르며 예쁜 사례만 임의로 고르지 않는다. 사례 수를 성능의 분모로 사용하지 않고 해당 유형의 전체 건수를 함께 보존한다.

새 포착의 순증가와 오경보의 순증가가 저장 지표의 TP·FP 차이와 각각 일치하는지 혼동행렬 관계로 대조한다. 입력은 현재 관측, 정답은 정확히 다음 격자 관측이며 두 모델은 원래 정책 구간에서 고정한 각각의 경보 기준을 적용한다. 이 자료는 실제 대여 성공·실패·이동 감소·사용자 인터뷰를 대신하지 않는다. 선택 근거와 원본 모델 결과의 해시를 `example_selection.json`에 남긴다.

## 확률값의 의미를 추가로 진단한다

53개 개발 결과를 확인한 뒤 기본·공간전환·고정 결합 모델의 확률을 진단한다. [공식 확률 보정 설명](https://scikit-learn.org/stable/modules/calibration.html)에 따라 예측 확률 구간의 평균과 실제 0대 비율을 함께 표시한다. 같은 문서는 Brier가 보정 상태뿐 아니라 구분 능력도 반영하므로 낮은 Brier만으로 확률 보정이 더 좋다고 단정할 수 없다고 설명한다. 구간별 표본 수와 보정 전후의 [이진 Brier 정의](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.brier_score_loss.html)를 함께 확인한다.

10개 동일 너비 구간은 설명을 위한 사후 진단 설정으로 정한다. 빈 구간은 0%로 채우지 않고 NaN으로 남기며 표본 수를 CSV에 보존한다. 10구간 평균 절대 보정오차는 구간 선택에 의존하는 기술 통계로만 사용한다. 기존 cal 구간의 보정기를 그대로 읽고 valid 정답으로 재보정하거나 경보 기준을 다시 고르지 않는다. 전체 기록과 현재 양수 구간을 분리해 전체 점수가 시민의 선택 구간을 가리지 않도록 한다. 저장된 float32 원확률 복원의 수치 차이를 명시하고 기존 Brier와 선언한 허용 오차 안에서 일치하는지 검사한다. 계획은 `calibration_diagnostic_plan.json`에 남기며 독립 최종 시험이나 운영 확률의 보장을 주장하지 않는다.

## 추가 공공데이터를 실제 입력으로 준비한다

세 조사 작업의 62개 후보 가운데 버스정류소 위치와 선행월 대여·반납 흐름부터 정제한다. 자료 선택과 규칙은 [준비계획](../20261020_추가공공데이터적용/준비계획.md), 정확한 입력 수식·로그 표현·결측 마스크·시점 기준은 [특징 정의와 근거](../20261020_추가공공데이터적용/특징정의와근거.md)에 남긴다. 원천은 서울시 OA-15067·OA-21229이며 거리/이동 연결의 가설은 Bike GCNN의 원논문 초록을 참고한다. 논문의 회귀 성과를 이번 0대 분류 성과로 옮겨 쓰지 않는다.

2024년 11월 흐름의 30개 구성원을 전수 읽어 6,364,061행을 확인한다. 11월 27일은 UTF-8 헤더만 있고 나머지 파일은 CP949인 예외를 찾는다. 엄격한 헤더 해독으로 처리하고 비어 있는 날을 실제 0건으로 채우지 않는다. 출발/도착 시간 기준을 따로 집계하고 출발 기준만 이동 관계에 더해 이중 계산을 피한다. 평균은 행이 나타난 날짜로만 계산하며 수록률과 결측 마스크를 함께 보존한다. 파일에 기록이 있는 날도 모든 실제 이동의 완전 수록을 보장한 것으로 부르지 않는다.

현재 ST-ID 교차표의 번호·정규화 이름·50m 조건과 과거 기록의 ID 존재를 확인한 2,493곳을 조건부 연결한다. 코호트 2,729곳을 줄이지 않으며 미연결 수치는 결측으로 유지한다. 50m는 프로젝트의 보수적 연결 기준이며 과거 동일성을 입증한 논문 임계값이 아니다. 당시에 받은 마스터·최초 공개·수신·원본 불변과 자정을 넘는 이동의 기준 날짜 의미는 미검증으로 표시한다.

건수 합 보존·이동 관계 합 보존·노출 분모·누락 날짜·미연결 결측을 검수하고, 별도의 표준 CSV 읽기로 첫날 집계를 대조한다. 추가 입력 연결의 자정/요일 전환·입력 순서·중복·공개 전 차단·미연결 마스크 검사 3개를 통과한다. 기존 v4 결과는 변경하지 않고 버스 4개·흐름 7개·결합 11개를 같은 기준 모델에 추가하는 후속 9개 비교를 별도 계획으로 남긴다. 입력 준비와 실제 후속 학습 성과를 구분하며 조건부 비교를 주 운영 성과로 바꾸어 제시하지 않는다.
