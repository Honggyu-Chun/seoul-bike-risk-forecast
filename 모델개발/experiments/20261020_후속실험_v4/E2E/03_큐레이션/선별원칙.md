# 자료 선별

같은 대여소·시각에 같은 값이 반복되면 한 관측으로 합친다. 값이 서로 다르면 원인을 입증하기 전까지 해당 키 전체를 제외한다. 값들을 더하거나 마지막 행을 정답으로 고르지 않는다. 기존 대여소 코호트와 좌표를 유지한다. 2024년 7월 표본에서는 같은 이름·시각에 7·8·9대가 함께 나타나는 사례를 확인한다. 세부 원인은 확인하지 못한다.

공개 달력·기록 시각에 맞는 수량과, 사후 수정 가능성이 남은 기상·행사 스냅샷을 분리한다. 원본 파일·해시·API 상태는 상위 기록과 audit JSON에 보존한다.
