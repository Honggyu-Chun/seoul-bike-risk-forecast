# 따릉이 부족 위험 예측: 지금까지 확인한 내용

이 문서는 2026-10-20 전원 대비 중간 저장본으로 작성한다. 모든 실험이 끝났다는 의미로 사용하지 않는다. 최신 숫자는 `leaderboard.csv`와 `실험결과.md`에서 확인한다.

## 무엇을 알아내려 하는가

지금 자전거가 있는 대여소도 다음 시간에 비어 있을 수 있다. 현재 수량과 과거 변화를 학습해 정확히 다음 정시 격자의 수량이 0인지 예측한다. 시민이 실제로 자전거를 빌렸는지까지 측정한 자료는 아니므로 대여 성공률이라고 표현하지 않는다.

## 1~4단계: 자료를 이해하고 사용할 상태로 만든다

1. 문제 정의에서 정답, 비교 기준과 평가 기간을 고정한다.
2. 탐색에서 2025년 1~6월 2,729개 대여소의 관측 약 1,170만 건을 확인한다. 현재·다음 관측이 모두 있는 평가 가능 행은 11,689,962건이며, 다음 시간 0대는 약 9.73%로 확인한다. 같은 행을 여러 모델이 공유하므로 실험 횟수를 곱해 독립 자료 수를 부풀리지 않는다.
3. 큐레이션에서 2024년 중복값 충돌 약 268만 키를 제외한다. 2025년 1월 9~10일 전체 누락도 확인하며 빈 대여소로 채우지 않는다.
4. 전처리에서 과거 수량·증감·지속 시간·주변 대여소·과거 전환 빈도를 특징으로 만든다. 학습·조기 종료·확률 보정·판단 기준 선택·바깥 검증을 서로 다른 시간으로 나눈다.

각 단계의 CSV·JSON 분석 결과와 PNG·SVG 그림을 `E2E` 폴더에 저장한다. 그림의 결론과 전체 행 통계를 구분하며 특징 분포 검수에는 고정된 과거 10만 행 표본을 사용한다.

## 5~6단계: 실제 학습 결과를 비교한다

기준 7개를 3개 개발 기간에서 비교한 21건을 완료한다. 현재 상태 유지, 전일·전주 규칙, 평활 Markov, 로지스틱, Random Forest, 기본 LightGBM을 포함한다.

| 비교 | 현재까지 확인한 결과 |
| --- | --- |
| 현재 상태 유지 | 세 기간 평균 F1 약 71.76%를 기록한다. |
| 기본 LightGBM | 같은 세 기간 평균 F1 약 72.67%를 기록해 약 0.91%p 차이를 확인한다. |
| 공간·전환 특징 LightGBM | 첫 기간 A에서 F1 약 74.16%를 기록한다. 같은 A의 상태 유지 72.14%보다 약 2.01%p 높지만 다른 기간 확인은 아직 끝내지 않는다. |
| 새로 비게 되는 대여소 찾기 | A에서 공간·전환 LightGBM의 전환 재현율 약 28.47%를 확인한다. 해당 부분집합에서 놓치는 위험과 오경보도 함께 비교해야 한다. |

F1은 놓치는 위험과 오경보를 함께 고려하는 점수로 사용한다. 71.76%에서 72.67%로 변한 차이는 0.91%p로 표현한다. 실제 대여 성공률이 0.91% 늘었다고 표현하지 않는다. 위 결과는 개발 검증이므로 최종 독립 시험 점수로 제시하지 않는다.

CatBoost·XGBoost·날씨를 제외한 기존 50:50 구조, 학습 기간·전년도·달력·시간 신경망·이웃 신호 비교는 후속 큐로 이어간다. 완료되지 않은 후보에는 성과 숫자를 채우지 않는다.

## 추가 데이터는 실시간 조건을 확인한다

실시간 따릉이 조회에서 2,716개 대여소와 기존 코호트 2,618개의 연결을 확인한다. 수신 시각을 보존하며 공급자가 측정한 시각을 임의로 만들어 넣지 않는다. 과거 시간별 수량과 현재 API 수량이 같은 정답 정의로 연결되는지 확인해야 한다.

대기질은 과거 학습 자료와 현재 25개 구 API 연결을 확보한다. 한 번의 조회에서 15시 관측을 16시 무렵 수신해 약 60분 지연을 확인한다. 이를 지연의 최대 보장으로 해석하지 않고, 2~3시간 전 자료와 수신시각·결측·오래된 자료 처리 조건을 구현한 뒤 주 입력으로 검토한다.

문화행사 19,642건을 수집하지만 당시 수정 이력을 입증하지 못한 과거 스냅샷은 주 비교에서 제외한다. KOPIS는 키 작동과 부분 목록 3,273개를 확인한 뒤 서버 차단 응답을 받아 중단한다. GFS 예보는 현재 받을 수 있는 경로를 확인하되 과거 발표 시점 검증을 추가로 수행한다. 세부 증거를 `추가데이터_병렬조사`와 `API와추가데이터.md`에 저장한다.

## 7단계: 저장하고 이어서 확인한다

성공한 모델·예측·보정기·결과 JSON, 코드, 표와 그림을 PC에 저장한다. 저장 모델의 예측값 재현 검사는 완료 후보에 대해 통과한 기록을 남긴다. 기존 보호 파일 23개의 해시가 일치함을 확인한다. 2025년 3·4분기 성능은 아직 열지 않는다.

현재 학습 중 후보의 메모리 상태까지 저장한 것은 아니다. 전원이 꺼지면 완료되지 않은 그 후보만 다시 학습한다. `D:\P실무\이어서_작업하기.md`의 명령과 체크포인트를 읽어 재개한다. 최종 보고서에는 모든 실제 비교, 추가 데이터 채택 여부, 실시간 운영에 남은 조건을 정리한다.
