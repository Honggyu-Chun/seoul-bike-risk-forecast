# 학습 중단과 저장 방식 보강

- 완료 결과 25건을 보존한 상태에서 B CatBoost의 실행 프로세스와 세션이 사라졌음을 확인한다. 성공 JSON이 없는 B CatBoost만 다시 시작한다.
- 학습 성능을 바꾸는 설정·특징·학습 순서·정지 기준은 유지한다. 새 CatBoost 학습의 출력 설정에만 60초 간격 중간 저장을 추가한다.
- 학습·조기 정지 입력의 모든 값과 열 순서·자료형, 설정, 라이브러리 버전을 해시로 기록한다. 입력이 바뀌면 이전 중간 저장본의 재사용을 거부한다.
- Windows의 한글 경로 문제를 피하도록 작업 폴더 기준 ASCII 상대 경로를 사용한다. 모델·중간 저장본의 실제 위치는 D 드라이브 프로젝트 안으로 유지한다.
- 중단 모사 후 재개한 45개 트리의 예측이 처음부터 학습한 결과와 일치하는 검사를 통과한다. 작은 검사는 저장·복원 검증으로만 기록하고 성능 비교 건수에 포함하지 않는다.
- 새 학습의 저장 위치는 `artifacts/followup_v4_20261020/{폴드}/snapshots/catboost_temporal/state.cbsnapshot`으로 정한다.
- 전원이 꺼지면 마지막 저장 이후의 연산과 학습 준비 과정은 다시 수행할 수 있다. RAM 전체 복원을 보장한다고 표현하지 않는다.

CatBoost [공식 중단·복원 문서](https://catboost.ai/docs/en/features/snapshots)의 동일 폴더·동일 설정 재개 방식과 `save_snapshot`, `snapshot_interval`, `snapshot_file`의 정의를 근거로 적용한다.
