## 바꾸지 않는 목표와 상한

기존 목표는 F1 +5%p, 재현율 비악화, 거리 기준 대비 유효추천율 +5%p, 추가 직선거리100m 이하이다. 기존 시험의 거리 기준 유효추천율95.1761%에서 +5%p는100.1761%이므로 해당 서비스 목표는 같은 시험에서 달성할 수 없다. 목표를 낮춰 달성한 것으로 바꾸지 않는다. 모델 F1 개선 및 추천의 실제 개선 폭은 별도로 연구한다.

## 원칙

더 많은 탐색 예산을 사용했으므로 단지 입력 정보 하나의 인과 효과가 입증되었다고 표현하지 않는다. 각 후보의 시간·데이터량·선택 기준·오류도 남긴다. 최종 시험이 목표에 못 미치면 그 결과를 숨기거나 같은 시험으로 다시 튜닝하지 않는다. 다음 실험에는 별도의 새 시험이 필요하다.

## 개발 중 추가한 검증 선택 방식

초기 클래스 가중치 실험에서 logloss 학습을 길게 해도 F1이 좋아지지 않는 경우를 확인했다. 완료한 결과는 보존하고, 아직 끝나지 않은 LightGBM 후보와 후속 refit은 검증자료의 F1을 직접 추적하는 checkpoint 선택을 추가했다. 기존 B1 대조군은 원래 logloss 선택을 유지한다. 이 변경은 새 시험 평가 전에 이루어졌으며 모델별 spec.select_f1과 코드 해시에 기록한다.

추가7개 전환 이력 특징은 현재까지 관측한 q(t-1)→q(t)만 누적한다. 검증·시험 중에도 새로 관측된 과거 수량으로 이력이 갱신되는 rolling 예측이며 q(t+1) 정답을 입력하지 않는다. 원래98개 특징 그룹은 유지하고, 전환 특징 그룹만 확장했다. 작은 신경망4개는 전체 학습 자료 중 고정120만 건을 사용하므로 전체 표본의 트리 모델과 학습 예산이 같다고 주장하지 않는다.

추가 CPU 한 개가 비어 있는 동안, 3월 최고 신경망 한 개만이 아니라4개 작은 신경망 모두를1~3월로 재학습하여4월 검증에서 비교하기로 확장했다. 이 결정은 새 시험을 열기 전에 했으며, 감독 프로세스가 추가 작업 완료를 기다린 뒤 최종 선택을 고정한다. 대여자에게 중요한 양수 구간에서도 더 조정한B1_tuned를 추가 대조군으로 함께 보고한다.

기상청 서울108 지점2025년8,760시간 공식 원본을 실제로 추가 비교한다. 기존80/105개 전환 특징 그룹에 1·24시간 전의 관측 날씨11개를 추가한 후보2개이며 기존 그룹의 값은 바꾸지 않는다. 비·눈 빈칸은0으로 바꾸지 않는다. 과거 파일의 사후 품질수정 및 실시간 게시 지연·동일 버전 제공은 확인하지 못했으므로 관측시각 기준의 과거 민감도 실험으로 해석한다. 이 추가 결정 역시 새 시험을 열기 전에 했다. source SHA와 범위는artifacts/improvement/weather_audit.json에 기록한다. 총1차 후보45개이며, 목적으로 분리한 모든 후보를 완료하기 전에 최종 시험을 열지 않는다.

새 시험 전 추가한 추천 보조 진단: 가장 가까운 현재 양수 후보에1~3대만 있는 요청을 따로 본다. 부분집합은 현재 수량으로만 정하고, 전체 검증에서 고른 추천 설정을 바꾸지 않는다. 이 부분집합 결과를 전체 +5%p 목표의 달성으로 대체하지 않는다.

후속 재학습은 상위 후보 외에 최상 CatBoost·XGBoost·상태분리 학습기와 최상 과거날씨 표현을 유지한다. CPU가 남는 동안 날씨·주변 후보를 먼저 재학습하고 감독 프로세스가 완료를 기다려 중복 학습을 막는다. 최종 선택 전 앙상블은 모든 완료 후보에서 다시 구성하므로 병행 작업의 종료 순서에 의존하지 않는다.

후속 후보의 중복 제한:1차 검증에서 같은학습기·같은입력의깊이/잎 변형은 최고만 대표로 삼고, 서로 다른(학습기 종류,입력 그룹)6개를 우선 유지한다. 여기에최상CatBoost·XGBoost·상태분리·과거날씨 표현과기본 대조군·신경망을 유지한다. 이는새시험을열기전정한자원배분이며, 같은계열의비슷한깊이를모두재학습하는대신다른입력·학습기도비교하기위함이다. 모든1차 후보는CSV에그대로남긴다.

최종 시험 전 추천 대조군R1u를 추가했다. 원래B1을M2와같이4/1~7에상태별확률보정하고,4/8~14에서같은7개위험·거리비용과평균추가거리100m조건으로선택한다. R1은기존경계제외방식을유지하므로R1과R1u로추천규칙의차이를보고, R1u와R2로같은정책계열에서모델을비교한다. 전체목표R2−R0 +5%p와모든분모는바꾸지않는다.

추천 차이의 불확실성도 새 시험 전 정의했다. 같은날짜·시각·출발지 요청을짝지어 전체요청분모를유지하고, 날짜단위2,000회재표집으로R2−R0/R1u/Rq의탐색적95%범위를보고한다. 정책선택에이범위를써서시험결과에맞추지는않는다.
