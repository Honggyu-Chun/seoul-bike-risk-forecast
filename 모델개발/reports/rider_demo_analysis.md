# 따릉이 시민용 데모: 실제 실험 분석

## 판단
웹 데모·공식 실시간 입력·실제 모델 비교는 구현했다. 그러나 주변 정보를 더한 M1의 우수성과 시민의 헛걸음 감소는 입증하지 못했다. 전체 F1의 작은 증가와 사용자 후보 구간의 낮은 전환 탐지율을 분리해서 해석해야 한다.

## 데이터와 정답
- 서울시 2025년 1분기 수량 원본 5,835,300행, 원본 번호 2,767개. 월별로는 각각 1,922,370/1,855,974/2,056,956행.
- 학습기간만으로 정한 변화·양수 관측·좌표 조건의 2,729개 대여소. 제외 38개. 공식 운영 상태가 확인되었다는 뜻은 아니다.
- 분기 전체 도시 공통 누락 50시간. 누락은 0이 아니다. 같은 대여소의 다음 격자 시각에 실제 기록이 있을 때만 다음 0대 여부의 정답으로 사용했다.
- 원본 열 거치대수량과 공식 페이지의 대여가능 수량 설명 사이의 집계시점·운영상태 의미는 완전히 확정되지 않았다. 실제 대여 실패 정답으로 해석하지 않는다.

## 기간과 모델 선택
- train: 2025-01-01T01:00:00.000000000~2025-02-28T23:00:00.000000000, 3,716,886건, 0대 320,686건.
- validation: 2025-03-01T00:00:00.000000000~2025-03-14T23:00:00.000000000, 916,608건, 0대 87,281건.
- test: 2025-03-15T00:00:00.000000000~2025-03-31T23:00:00.000000000, 1,112,738건, 0대 112,433건.
- 선택 설정·threshold·모델 해시는 selection_frozen_before_test.json에 최종 시험 예측 전 기록했다. B1/M1은 2개 후보, 240회 상한과 같은 조정 예산을 사용했다. 날씨는 공개시점 미확인으로 제외했다.
- B0는 현재 0대 여부 유지. B1은 자기 정보 16개 특징. M1은 같은 LightGBM에 주변 특징 11개를 추가해 총 27개. B1S는 현재 수량·시간 등의 6개 특징으로 별도 학습한 실시간 입력 참고 모형이며 B1을 대체하지 않는다.

## 실제 모델 결과
|모델|F1|정밀도|재현율|놓친 0대|
|---|---:|---:|---:|---:|
|B0|75.400%|75.365%|75.436%|27,618|
|B1S|75.416%|75.038%|75.798%|27,211|
|B1|75.741%|75.071%|76.423%|26,508|
|M1|75.766%|74.724%|76.837%|26,043|
- M1−B1 F1 +0.0245%p, 재현율 +0.4136%p, 정밀도 -0.3471%p.
- 놓친 0대는 465건 줄었지만 잘못된 위험 알림은 689건 늘었다. +5%p 목표 미달이다.
- 일 전체를 묶어 1,000번 짝지어 재표집한 F1 차이의 탐색적 95% 범위는 -0.0447~0.1038%p. 0이 포함되므로 확실한 개선이라고 결론 내리지 않는다. 시험은 17일로 짧고 장기 시간상관·계절까지 입증하지 않는다.

## 시민에게 중요한 구간
- 현재 양수인 곳의 다음 0대 전환: M1 재현율 9.396%, F1 15.462%. B1 F1 15.774%보다 낮았다.
- 전체 0대 위험은 현재도 0대인 상태의 지속을 많이 포함한다. 시민은 현재 자전거가 있는 곳을 고르므로 전체 F1 75%만으로 서비스가 충분하다고 말할 수 없다.

## 실제 추천 결과
|방법|유효추천 수/전체|유효추천율|보류율|짝지은 추가 직선거리|
|---|---:|---:|---:|---:|
|R0|4,972/5,224|95.176%|0.000%|0.00m|
|R1|4,987/5,224|95.463%|0.211%|2.40m|
|R2|4,982/5,224|95.368%|0.306%|2.00m|
- 출발지 120개는 학습 코호트 좌표에서 고정 난수로 만든 가상 위치다. 고정 평일 7·8·18·19시 총 5,280개 요청 중 현재 양수·목표 정답 후보가 없는 56개를 공통 제외해 5,224개를 평가했다.
- R2는 R0보다 10개 더 유효하지만 R1보다 5개 적었다. 공간 정보로 추천이 더 좋아졌다고 말할 수 없다.
- R0가 이미 95.176%여서 최대 추가 개선 여지는 4.824%p다. 초기 +5%p 서비스 목표는 이 시험에서 수학적으로 도달 불가능했다. 목표는 소급 수정하지 않았으며 후속 실험의 목표는 새 검증자료와 미사용 시험자료로 다시 설계해야 한다.
- 유효추천율은 보류를 분모에 남긴다. 추천 적중률만 제시해 보류를 숨기지 않았다. 실제 사용자 이동·대여·고장·반납은 관측하지 않아 현장 성공률과 다르다.

## 중요도와 실패
- 현재 수량의 gain 비중은 89.94%, 주변 특징 전체는 0.35%. gain은 모델 내부 분기 기여도이며 인과적 영향이나 실제 도로 연결을 뜻하지 않는다.
- 실패 사례·대여소별 점수·일별 점수·추천 요청별 기록을 각각 false_negative_cases.csv, station_metrics.parquet, daily_metrics.csv, recommendation_queries.parquet에 보관한다.

## 데모와 실시간 경계
- 과거 화면은 실제 M1/B1의 고정 시험 결과를 재생한다. 성공 사례와 불리한 사례를 함께 고를 수 있다. 좌표 위치도는 실제 보행지도·경로가 아니다.
- 실시간 화면은 공식 API의 현재 5곳 수량에 별도의 B1S를 실행한다. 현재 계절의 실제 미래 정답이 없으므로 정확도가 검증된 실서비스가 아니다. M1의 실시간 전체·과거 이력이 충족되었다고 표시하지 않는다.
- 발급키 전체 조회, 데이터 갱신 지연, 안정적 수집, 짧은 간격 정답 생성과 새로운 기간별 검증은 후속 과제다.

## 과제 평가에 대한 정직한 대응
- 문제 정의·실제 데이터·구현·객관적 Baseline 비교·재현 문서는 준비했다. 반면 “벤치마크 대비 우수성”을 강하게 뒷받침할 결과는 아직 부족하다. 이 약점을 발표에서 감추지 않는다.
- 후속 연구는 현재 양수·낮은 수량의 0대 전환 탐지와 사용자 선택의 비용에 맞춘 평가를 우선한다. 새 목표는 기존 시험 점수에 맞춰 소급 달성으로 바꾸지 않는다. 사용자 수요·기존 앱 기능·허용 추가 이동을 인터뷰로 확인한다.

## 재현
```bash
uv sync --frozen
uv run python -m bike_demo.train
uv run python -m bike_demo.evaluate_recommendations
uv run python scripts/analyze_rider_results.py
uv run python scripts/export_offline_demo.py
uv run pytest -q
bash scripts/run_demo.sh
```
모델 선택·시간 분할·raw 파일 확보는 README와 config/experiment_v1.json을 함께 확인한다. 이미 본 시험기간은 후속 개선의 새 독립 시험집합으로 재사용하지 않는다.
