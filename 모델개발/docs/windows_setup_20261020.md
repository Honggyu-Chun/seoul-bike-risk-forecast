## 작업 위치와 실행

실제 개발 폴더:

`D:\P실무\모델개발`

`D:\P실무` 폴더의 `START_P_PROJECT.cmd`, `STOP_P_PROJECT.cmd`, `SETUP_P_PROJECT.cmd`를 사용합니다. 시작 파일은 localhost 8000번 서버를 숨김 프로세스로 실행하고 준비 상태를 확인합니다. 이미 준비된 동일 데모가 있으면 재사용합니다. 로그와 서버 PID는 `reports/local_runs/windows_20261020/`에 저장합니다. 종료 파일은 저장한 PID의 실행 파일·명령을 검사하고 Windows Python 자식 프로세스도 함께 종료합니다.

개발 폴더에서 직접 실행할 때:

```powershell
$env:PYTHONUTF8 = '1'
.\.venv\Scripts\python.exe -X utf8 -m uvicorn bike_demo.api:app --host 127.0.0.1 --port 8000
```

테스트:

```powershell
$env:PYTHONUTF8 = '1'
.\.venv\Scripts\python.exe -X utf8 -m pytest -q
```

한글 경로와 UTF-8 파일을 위해 `PYTHONUTF8=1` 또는 `-X utf8`을 유지합니다. 일반 실행은 설치된 `.venv`를 직접 사용하여 선택 연구 의존성을 제거하지 않습니다. uv로 실행한다면 `uv run --frozen --no-sync`를 사용합니다.

3. `scripts/check_demo_browser.py`: 브라우저 실행 파일과 결과 폴더를 인자로 선택하도록 확장했습니다. 기존 Linux 경로와 기본 출력은 유지하며, 로컬에서는 설치된 Chrome과 별도 결과 폴더를 사용했습니다.
4. 두 독립형 HTML은 같은 기존 예측·결과로 다시 내보냈습니다. 학습·최종 시험 재평가는 하지 않았습니다.

모델 선택·연구 코드 3개·프로토콜·모델 4개·보정기 2개의 고정 해시는 보존했습니다. Windows 연구 의존성 설치·테스트는 확인했지만, 모든 과거 실험의 Windows 재학습이나 OS 간 수치 동등성을 검증했다는 뜻은 아닙니다. 후속 연구에서 다른 LightGBM 네이티브 파일 저장·로드를 사용하면 한글 경로 지원도 확인합니다.
