# 따릉이, 어디로? — 데모 2.0 사용 안내

2026-10-20 KST 기준. 시민의 대여소 선택을 실제로 탐색할 수 있도록 화면과 API를 확장했습니다. 대여소 탐색은 기존 M1의3월 시험을 재생하며, 후속 성능 개선 연구는 결과 화면에서 따로 확인합니다.

## 먼저 여는 파일

`deliverables/따릉이_시민용_서비스데모_v2.html`을 브라우저로 열면 코드 설치 없이 체험할 수 있습니다. 과거 시각 12개가 포함되어 있고, 그 시각의 대여소·지도·24시간 이력·실험 결과를 사용할 수 있습니다. 지도와 이력도 파일 안에 있어 외부 연결에 의존하지 않습니다. 최신 HTML의 별칭은 `따릉이_시민용_오프라인데모.html`입니다.

전체 과거 시험 시각과 공식 API 수신을 보려면 실행 패키지를 풀고 서버를 실행합니다.

```bash
cd P_Project
uv sync --frozen
bash scripts/run_demo.sh
```

Windows 등 Bash가 없는 환경에서는 `uv run --frozen uvicorn bike_demo.api:app --host 0.0.0.0 --port 8000`으로 실행합니다. Python3.12와 uv가 필요하고, Linux에는 OpenMP 런타임이 필요합니다. 현재 클라우드에서 동작을 확인했으며 새로운 PC에서 의존성을 설치하는 과정 전체를 검증한 것은 아닙니다. 이 패키지는 전체 원본 ZIP 없이 실행되도록 모델·시험 예측·이력 패널을 포함합니다. 원본 재학습은 README의 절차를 따릅니다.

서버 포트8000을 해당 실행 환경의 브라우저 방식으로 엽니다. 외부 공개 도메인에 배포한 상태는 아닙니다.

## 시민용 탐색 기능

1. **출발 위치**: 대여소 이름·번호·자치구로 검색하거나 주요 지역 버튼을 누릅니다. 검색은 키보드의 아래 화살표·Enter로 선택할 수 있습니다. 지도에서 직접 출발지를 정하거나 브라우저 위치 권한을 허용해 내 위치를 사용할 수도 있습니다. 현재 위치를 사용해도 과거 모드 수량의 기준 날짜는 선택한 2025년 날짜입니다.
2. **주변 범위**: 직선500m·1km·1.5km 중에서 고릅니다. 공식 비교 실험의 범위는500m이며 다른 범위는 탐색 기능입니다. 지도는 통계청2013 행정구역 경계 기반 참고도로, 실제 보행 길·도보 시간을 보여 주지 않습니다.
3. **시간 이동**: 날짜·시간·앞뒤 버튼·슬라이더·자동 재생으로 실제 기록의 변화를 봅니다. 누락 시간은 임의로 생성하지 않습니다. 다음 기록의 실제 수량은 검증 스위치를 켰을 때만 표시합니다.
4. **선택 방식 비교**: R0는 현재 양수인 가장 가까운 곳, R1은 B1 위험을 제외한 가까운 곳, R2는 M1 위험을 제외한 가까운 곳입니다. 조건에 맞는 곳이 없으면 보류합니다. 카드를 누르면 그 대여소의 상세 정보가 열립니다.
5. **후보 탐색**: 현재 양수·위험 낮은 곳·즐겨찾기 필터와 거리·수량·점수 정렬을 제공합니다. 처음8곳을 표시하고 목록을 더 펼칠 수 있습니다. 전체 현재 필터 결과는 CSV로 내려받을 수 있습니다.
6. **상세 정보**: 실제 주소, 선택 시각 수량, B1/M1 참고 신호, 선택 시각까지 지난24시간 관측, 500m 이웃의 수량을 보여 줍니다. 누락 이력은0으로 채우지 않고 선을 끊습니다. 주변 수량은 상황 정보이며 개별 예측의 원인을 입증하는 분석은 아닙니다.
7. **저장·공유**: 하트로 최대50곳을 이 브라우저에만 저장합니다. 탐색 설정 링크에는 위치·시각·범위·선택 대여소·모델이 들어갑니다. 받는 사람도 같은 데모 주소에 접근할 수 있어야 하며, 오프라인은 HTML 파일도 전달해야 합니다.
8. **지도 연결**: 선택 대여소의 카카오맵 위치 링크로 실제 길을 확인할 수 있습니다. 외부 지도 연결에는 인터넷이 필요합니다. 경로·이동시간을 데모가 계산한 것으로 표시하지 않습니다.

## 후속 성능 개선 결과 읽기

결과 화면은 **후속 M2 · 4/15~5/14 시험**과 **기존 M1 · 3/15~31 시험**을 구분합니다. 각각 같은 기간에 다시 확인한 기본 모델과 비교하며, 두 기간의 점수를 빼서 개선 폭으로 계산하지 않습니다. 연구가 진행 중이면 개발 검증 점수라는 표시가 나오고, 새 시험 결과가 생기면 실제 결과표로 바뀝니다.

새 표에서는0대 경고 성능과 추천 효과를 따로 봅니다. B1은 원래 기본 모델, B1+는 자기 정보로 더 조정한 기본 모델, M2는 검증자료에서 선택한 후속 모델입니다. 추천은 가까운 곳 R0, 원래 기본 AI R1, 제안 방식과 같은 위험·거리 규칙을 쓴 기본 AI R1u, 현재 수량과 거리만 쓰는 Rq, 제안 AI와 거리를 쓰는 R2를 비교합니다. +5%p는 초기 팀 목표이며 학교가 정한 합격선이 아닙니다.

최종 보고서가 준비되면 서버 화면에서 Word를 내려받을 수 있습니다. 오프라인 HTML에는 내보낸 시점의 결과표가 들어가며, 보고서 파일은 실행 패키지 안에서 따로 엽니다. 지도 탐색은 기존 M1의 재생 화면이므로 새 M2 표와 혼동하지 마세요. 과거 날씨를 사용한 M2라면 실시간 게시 지연·같은 품질의 제공 여부가 미검증임을 함께 표시합니다.

## 실시간 화면의 의미

공식 샘플5곳의 현재 수량과 B1S 기본 모형 참고 신호를 제공합니다. 최초 화면은 망원·합정 샘플 인근을 보여 줍니다. 실시간에서는 반경 필터 대신 샘플 전체5곳을 표시합니다. 발급키가 있다면 전체 조회 코드에 연결할 수 있으나, 발급키를 사용한 서울 전체 조회는 아직 검증하지 않았습니다.

수신시각·수신 후 경과·캐시 재사용 여부를 표시합니다. 선택하면60초 간격으로 현재 화면을 보는 동안만 갱신하고, 다른 탭·숨긴 브라우저에서는 중단합니다.120초 이상 지난 수신 자료는 재조회 권장 상태로 바뀝니다. 이는 서버 수신 경과 표시이며 원천 데이터 갱신 지연을 보증하지 않습니다. 호출 실패 때 이전 값이 남으면 이전 수신 자료임을 명시합니다.

현재 수량이 모델에 들어가 점수가 계산되는 것은 확인했습니다. 현재 계절의 정확도, 실시간 M1,5~10분 뒤 정확도, 실제 대여 성공은 검증하지 않았습니다.

## 발표용 3~5분 시연

상단 **발표 시연** 버튼으로5단계를 진행할 수 있습니다.

1. **문제 제시**: 현재 수량·미래 위험·거리가 같은 화면에 있다는 점을 보여 줍니다.
2. **세 선택 비교**: 도움된 실제 사례의 R0/R1/R2를 보여 줍니다. 이 사례에서 B1/M1이 같은 곳을 골랐다면 M1만의 성공처럼 설명하지 않습니다.
3. **상세 확인**: 선택한 대여소의24시간 이력과500m 이웃을 확인합니다.
4. **불리한 선택 공개**: M1이 더 멀고도 다음 기록0대인 곳을 고른 사례를 보여 줍니다.
5. **전체 수치로 결론**: 상단의 후속 새 시험은 B1 F1 72.959% → M2 74.070%, 추천94.082% →98.104%입니다. 아래 기존3월 M1 시험은75.741% →75.766%로 별도 비교합니다. 지도 사례는기존M1, 새M2는결과표라는구분과초기+5%p미달·실제대여성공미검증을함께설명합니다.

네트워크를 쓰는 실시간 입력 시연은 위의 과거 검증과 별도로 보여 줍니다. 인터넷이 되지 않으면 오프라인 모드에서 실제 과거 수량과 사례만 설명합니다.

## 검증·코드 위치

- `bike_demo/api.py`: 과거 조회·대여소 상세·도시 전체·실시간 API. 상세 이력은 입력 시각까지의 원본 관측만 반환합니다.
- `bike_demo/static/`: 화면, 지리 참고도, 검색·비교·공유·즐겨찾기·시연 로직.
- `scripts/export_offline_demo.py`: 이력·지도까지 포함한 독립 HTML 생성.
- `scripts/check_demo_browser.py`: 실제 브라우저 기능·장애 주입·모바일·오프라인 확인.
- `artifacts/browser/v2/checks.json`: 수행 결과. 오프라인 검사는 빈 브라우저에 실제 HTML만 공급하고 첫 렌더링부터 다른 네트워크를 차단합니다. 관리 브라우저의 파일 프로토콜 직접 열기는 미검증입니다. 의도적으로 주입한 API 장애는 실제 제공기관 장애와 구분합니다.
- `docs/map_sources.md`: 지도 참고도의 원출처·연도·라이선스.

과제계획서와 기존 팀원용 상세 설명서는 기존 M1 실험의 설명에 사용할 수 있습니다. 후속 M2 수치는 별도 성능 개선 보고서를 우선합니다. 기존 문서의 화면 캡처·26개 테스트 표기는 초기 데모 기준이므로, 화면 설명은 이 안내와 `artifacts/browser/v2`의 최신 캡처를 우선합니다. 현재 연구 의존성까지 설치한 클라우드의 자동 테스트는40개입니다.
