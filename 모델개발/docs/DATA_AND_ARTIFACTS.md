# 데이터와 모델 준비

## GitHub에서 제공하는 범위

소스 코드, 의존성 잠금 파일, 실험 설정, 출처·다운로드 명세, 가벼운 성과 JSON·CSV, 생성한 표·그림·보고서와 최신 제안서를 제공한다. 대용량 파일은 Git 이력과 분리해 [실행 자료 릴리스](https://github.com/Honggyu-Chun/seoul-bike-risk-forecast/releases/tag/runtime-20261021)에 제공한다. 준비 도구는 고정한 크기·SHA-256·파일별 해시를 대조해 설치한다.

## 바로 실행하는 데이터·모델

| 프로필 | 다운로드 | 포함 범위 |
| --- | --- | --- |
| `demo` | 약 28.6MB, 12개 파일 | 2,729개 대여소 메타데이터, 2025년 1분기 수량 패널, 고정 과거 예측·추천 자료, B1·M1·B1S와 메타데이터, 오프라인 화면·기존 결과 보고서를 제공한다. |
| `research` | 약 36.1MB 추가, 8개 파일 | `demo`에 더해 2024년·2025년 상반기 패널·검수 기록과 A 구간 기본·공간 LightGBM 2종 및 보정기를 제공한다. |

Python 프로젝트 폴더에서 `python scripts/setup_runtime.py --profile demo` 또는 `--profile research`로 준비한다. 정확한 경로·파일 크기·해시·주소는 [실행 자료 명세](../config/team_runtime.json)를 따른다. 기존 파일이 같은 해시이면 재사용하고 다르면 덮어쓰지 않는다. API 키·개인별 이동기록·가상환경·사본 소스 코드·새 제안서의 1~3시간 예측 모델은 묶음에 넣지 않는다.

기존 시제품과 모델 검토를 위한 묶음으로 구분한다. 최신 제안서의 2022~2025년 전체 원본·모든 비교 모델·전체 특징 행렬을 제공한 것으로 해석하지 않는다. 상세 설치와 역할별 작업 위치는 [팀원 첫 실행 안내](TEAM_SETUP.md)를 따른다.

이전 전체 전달용 자료는 `transfer/local-codex-20261020` 브랜치에 보존한다. 일상 협업에는 `main`을 사용한다. 전달 브랜치는 백업 복원용으로만 구분하며 최신 로컬 실험 전체를 담았다고 가정하지 않는다.

## 공식 원본과 명세

작업 위치는 Python 프로젝트 폴더인 `모델개발`로 한다. 공식 URL·파일명·해시·저장 위치는 다음 명세에서 확인한다.

| 명세 | 내용 |
| --- | --- |
| `data/downloads.json` | 기존 연구의 원본 다운로드 조건을 확인한다. |
| `data/improvement_downloads.json` | 기존 후속 연구의 수량 원본을 확인한다. |
| `data/weather_research_downloads.json` | 기존 연구의 관측 기상 원본을 확인한다. |
| `experiments/20261020_데이터방법론조사/availability_downloads.json` | 이후 확보한 수량 자료와 검수 상태를 확인한다. |

기존 명세 기반 다운로드 도구는 다음과 같이 실행한다. 원천의 접근 가능성·이용조건·다운로드 크기를 확인한 뒤 필요한 자료만 선택한다.

```bash
uv run --frozen --no-sync python scripts/fetch_public.py --manifest data/improvement_downloads.json --raw-dir data/raw/improvement
```

이 명령은 최신 제안서의 2022~2025년 전체 범위를 자동 완성하는 명령이 아니다. 새 기간·원천은 별도 명세와 검수를 작성한다. 이미 확인한 시험 기간은 새 독립 시험으로 사용하지 않는다.

## 기존 시제품의 실행 조건

기존 API는 `artifacts/models`의 모델과 `artifacts/evaluation`의 가공자료 등을 필요로 한다. `demo` 준비가 이 파일들을 제공한다. `python scripts/check_runtime.py`로 화면·과거 예측·결과표·보고서·오프라인 화면을 확인한다. [기존 시제품 안내](demo_v2_guide.md)와 [기존 연구 코드 안내](../README.md)는 과거 1시간 시제품의 기록으로 구분한다.

현재 작업 PC의 전체 자료는 프로젝트 안의 `data`, `artifacts`와 로컬 백업에 보존한다. 릴리스 묶음 외의 자료가 필요하면 명세를 통해 원본을 확보하고 전처리를 재현한다. 모델·특징 순서·코호트·보정기·설정을 같은 버전으로 대조하며 가중치가 없을 때 임의 모델로 기존 성능을 표시하지 않는다.

## 새 개발과 추가 API

최신 개발 범위는 1·2·3시간 뒤 0대 예측과 2022~2025년 자료 확장으로 한다. 기존 v4는 2025년 상반기 1시간 예측의 개발 비교로 보존한다. 새 범위를 구현할 때는 새 자료·특징·정답·분할·출력 폴더를 정의한다.

공개 원본만 사용하는 실험에는 API 키가 필요하지 않을 수 있다. 실시간 따릉이·추가 자료는 `.env.example`을 참고해 각 제공기관의 키를 별도로 준비한다. 키를 저장소·클라이언트 코드·결과 로그에 포함하지 않는다. 과거 아카이브의 시각과 실제 당시 발표·수신 시각은 다를 수 있으므로 운영 적격성을 따로 검수한다.
