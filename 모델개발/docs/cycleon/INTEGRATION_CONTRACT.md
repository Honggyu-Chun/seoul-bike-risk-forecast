# 프론트 백엔드 AI 연동 계약

AI API v1과 내부 데이터 API는 구현·OpenAPI 기준으로 준비돼 있다. 아래 고정 규칙을 보존하면서 각 파트의 구현을 진행한다. 앱의 공개 API는 이 문서에서 임의로 확정하지 않는다.

## 이미 정해진 입력과 출력

| 구간 | 요청 | 반환·책임 |
| --- | --- | --- |
| 앱 백엔드 → AI status | GET `/v1/status` | 기준 정각·지원 목표·모델/자료 준비 상태 |
| 앱 백엔드 → AI predictions | POST `/v1/predictions`, station_ids·horizons_hours | 항목별 확률·판정·모델·null 사유·최신 재고 |
| 앱 백엔드 → AI recommendations | POST `/v1/recommendations`, 위도·경도·horizon_hours·radius_m | 추천1·대안 최대2 또는 abstained와 reason |
| AI → 데이터 백엔드 | GET `/internal/ai-data/v1/stations`, `/observations`, `/forecasts` | station_id·좌표·원시 수신 이력·발표/목표 시각·품질·커서 |

사용자 요청 body에 재고 이력·기상·특징 벡터를 넣지 않는다. AI가 별도 동기화 캐시와 학습 공유 코드로 특징을 생성한다. 앱 백엔드가 제공하는 대여소 목록에는 공통 문자열 station_id·name·latitude·longitude가 필요하다. 예측 응답은 이름/좌표를 포함하지 않는다.

## 모든 파트에서 같은 의미로 사용할 규칙

- 기준은 최근 정각이다. 14:40 조회에서 14:00 기준 15/16/17시를 예측한다. `base_at`, `target_at`, `supported_targets`를 사용한다.
- 시각은 오프셋 포함 ISO 8601, 화면 표시는 KST다. 현재 재고의 수신 시각과 모델 기준 시각을 합치지 않는다.
- risk_probability는 0~1 범위의 목표 정각 0대 확률이다. 미래 수량이나 대여 성공 확률이 아니다. is_risk는 AI의 저장 임계값 판정이다.
- 확률0, 재고0, is_risk=false는 유효 값이다. null은 불가/미확인이다. 일부 항목 null을 전체 서버 오류로 바꾸지 않는다.
- 현재0대도 예측한다. 추천은 정상 ID·유효 예측·현재 양수·수신 나이0이상300초미만인 후보로 제한한다.
- 기본500m·최대1500m 직선거리이며 자동 확대하지 않는다. 추천1곳·대안 최대2곳이다. score는 거리 포함 정렬 점수로 확률과 다르다.
- 인증된 AI의401은 서비스 설정 문제일 수 있다. 앱의 사용자401과 구분해 매핑한다. 422·timeout·500·보류 reason을 각각 처리한다.
- 같은 v1 안에서도 model_id·보정·임계값은 바뀔 수 있다. 모델 ID를 화면에 고정하지 않는다. 미지의 reason에는 일반 불가 상태를 제공한다.

## 회의에서 합의할 항목

| 항목 | 결정해서 남길 값 |
| --- | --- |
| 프론트 공개 API | 실제 경로·메서드·요청/응답 JSON·대여소 목록 경로. AI 응답 그대로 중계/조합 중 선택 |
| 대여소 결합 | 공통 station_id와 매핑 책임, 이름·좌표·수량 출처, 이전/폐소 적용 시점 |
| 내부 데이터 구현 | 기존 계약 채택 또는 어댑터, 저장/조회·수신 cursor/watermark·완전 캡처 검증 |
| 사용자 인증과 서버 주소 | 앱 사용자 인증, 환경별 base URL. AI/공공 키는 서버 비밀 설정 |
| 갱신과 캐시 | 화면 갱신 주기·정각 변경·타임아웃·재시도·오래된 응답 무시 방식 |
| 오류 봉투 | 업무 보류/일부 null/입력 오류/서비스 접속 실패/서버 장애의 코드와 응답 형태 |

SQLite 참조 DB를 팀 DB로 강제하지 않는다. 실제 모델 입력 공급과 W/F/E 기상 제품·시간 계약은 [백엔드 명세](BACKEND_HANDOFF.md) 9절을 따른다. 현재 모델 연구는 확보한 과거 자료로 진행하며 상시 수집을 연구 선행 조건으로 두지 않는다.
