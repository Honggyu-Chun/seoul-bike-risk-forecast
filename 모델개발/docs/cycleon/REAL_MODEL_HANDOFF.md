# 실제 모델 연결 인수

목업으로 화면·중계·데이터 계약을 개발한 뒤 실제 모델로 전환한다. Git에는 가중치·실제 DB·API 키가 없으므로 Git 클론만으로 실제 예측이 준비되지는 않는다.

## 인수할 항목

| 항목 | 확인할 내용 |
| --- | --- |
| 접속 방식 | 모델 담당 서버를 호출할지, 팀 환경에서 번들을 로드할지 선택 |
| 번들 | manifest.json·모델 파일·번들 ID·manifest SHA256·h별 모델 SHA256 |
| 적용 경로 | 입력 columns·대여소 코드북/ID 검증·h1/h2/h3·이력 부족 C 대체·필수 입력 보류 |
| 보정과 정책 | h별 보정·임계값·추천 정책. 현재 개발 T/C 번들의 정책은 null |
| 데이터 | 세 내부 API·초기 약170h 이력·변경 커서·완전 캡처·수신 시각·품질 |
| 접속 설정 | AI/데이터 base URL·접근 방법·서비스 토큰. 실제 비밀값은 Git/브라우저로 전달하지 않음 |

현재 개발 번들은 `development_TC_20261027_v2`, manifest SHA256은 `91755fba0f8716d78eebf908bc0c7e0ab21117f0ebce17c77b5c9f1b1e77bacd`다. T/C 세 간격의 검증 이력이 있는 개발본이며 최종 모델이 아니다. S/C 권고 후보나 후속1시간 연구 결과를 이 번들에 적용된 것으로 해석하지 않는다. stage에 남은64개 문구는 당시 생성 이력이며 현재 필수 실험 수가 아니다.

## 원격 AI를 호출하는 경우

앱 백엔드의 `CYCLEON_AI_BASE_URL`과 `CYCLEON_SERVICE_TOKEN`을 별도 인수한다. `/v1/status`의 model_stage가 mock이 아닌지, 번들 ID·base_at·supported_targets·precompute_error를 확인한다. 실제 목록에서 station_id를 받아 세 간격 예측을 확인한다. `ST-MOCK-*`는 실제 ID가 아니다.

ready는 일부 유효 예측이 있다는 뜻이며 모든 대여소의 최신 재고나 추천 준비를 보장하지 않는다. 항목별 null·이력 부족·최신 수신 나이와 추천 보류를 확인한다. 서버가 내려가 있으면 SSH 터널만으로 복구되지 않는다. 접속 방식·서비스 실행은 별도 인수 후 진행한다.

## 팀 환경에서 번들을 로드하는 경우

Python3.12 별도 환경에서 `requirements-serving.txt`를 설치한다. CatBoost 멤버를 쓸 때만 그 번들의 검증된 CatBoost 의존성을 추가한다. 현재 T/C는 LightGBM이다. 모의 환경과 실제 모델 환경을 분리한다.

`scripts/cycleon_service.py ai --bundle <전달받은_번들_폴더> --backend-url <내부_데이터_API_주소> --port <팀_AI_포트>`가 참조 실행 경로다. `CYCLEON_SERVICE_TOKEN`과 쓰기 가능한 `CYCLEON_RUNTIME_DIR`은 서버 환경변수로 지정한다. 모델 로더는 manifest의 purpose·schema·경로·파일 SHA를 확인한다. 이 명령은 별도 팀 환경에서 인수 후 실행하며 연구실의 기존 서비스/수집기를 임의 재시작하지 않는다.

AI가 데이터 백엔드에서 이력을 동기화하므로 빈 DB에서는 null/미준비가 정상일 수 있다. 실제 수신 이력이 없는 시각을 생성하거나 missing을0으로 채우지 않는다. W/F/E는 BACKEND_HANDOFF9.2의 동일 제품·시각·정밀도 입력을 별도 인수한다. 기존 point 수집기 접근 성공을 raw-grid 운영 연결 완료로 보지 않는다.

## 전환 확인

- 번들·모델 파일 해시와 서빙 코드 버전을 함께 기록한다.
- 동일 입력의 저장 모델 추론, 보정, 세 간격·C 대체·null 경로를 재현한다.
- 앱 공개 API·대여소 목록·예측 시각·최신 수량·추천 보류가 화면까지 유지된다.
- 추천 성공은 선정된 정책이 있는 경우에만 검증한다. 현재 개발본 정책null과 합성 성공 화면을 구분한다.
- 실제 지연시간·연속운영·복구와 최종 독립평가는 각각 별도 완료 근거를 남긴다.
