정규 장기 이력 경로는 기준 재고·t−168h 관측·최근24h 최소12개 유효 관측을 요구한다. 부족하면 검증된 C로 전환하거나 null을 반환한다. 모델 조회 때 재학습하지 않는다.

## 후속 1시간 실험의 해석

11월2일4차 개발 비교에서 기존 F 고정 F1은75.97897%, 일별 지연 보정은76.31813%였다. 보정은 신규 고갈 재현율이16.80464%에서16.44683%로 내려가 비악화 조건을 충족하지 못했다. 직전3차 상태별 정책76.31579% 대비 추가F1은+0.00234%p로 작고7일구간은0을 포함했다. 스태킹도 같은 수정 정책의50:50결합보다 추가 이득이 없었다. **새 후보 최종 채택과 운영 교체는 없다.**

위는 이미 확인한5~6월4,059,021행의 **h1만** 비교한 결과다. h2/h3·하반기 독립 성과로 소개하지 않는다. 원래 스태킹 정책의 current==1 오류 결과는 무효이며, current>0 전체를 포함한 복구 결과만 설명한다. 일부 원실행 코드 스냅샷 한계도 원 보고서에 남겼다.

기존 M2 73.831%·v7 74.255%는 이전1시간 개발 비교로 위3간격 평균과 직접 비교하지 않는다. 가상 추천 결과도 실제 이용자의 대여 성공 효과와 다르다.

## 실제 모델과 서비스 인수

본 저장소에는 현재 서빙 참조 코드·특징 정의·보정 및 해시 검증 로더가 있다. 전체 연구 실행기·가중치·대량 원본을 설치 대상으로 제공하지 않는다. [실모델 인수](REAL_MODEL_HANDOFF.md)에 따라 번들·환경·데이터·주소·서비스 인증을 전달받는다. 모델 ID와 파일을 화면에서 고정하지 않는다.

11월2일 접속 확인에서8001/8002 listener는 없었다. Git의 실행 코드가 공용 서버 가동을 의미하지 않는다. 합성 목업은 로컬에서 직접 실행할 수 있다.
