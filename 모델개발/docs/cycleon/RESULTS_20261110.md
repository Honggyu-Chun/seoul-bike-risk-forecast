# 모델과 추천 평가 결과

2026년 11월 10일 저장된 최종 집계를 정리했습니다. 이 문서와 새 팀 HTTP 서비스의 합성 입력 검증은 구별합니다.

## 핵심 추천 비교

주 비교 기준은 **현재 양수 최근접(NP)** 입니다. 학습 예측기가 아닌 실용적인 비학습 추천 방식입니다. 2025년 7~12월, 120위치·평일 07/08/18/19시·1/2/3시간·반경 500m의 고정 요청 190,080건입니다.

| 항목 | NP | 엄격 아카이브 E_serving |
| --- | ---: | ---: |
| 추천 | 188,049 | 188,049 |
| 보류 | 2,031 | 2,031 |
| 목표 재고 0대 추천 | 12,800 | 5,280 |
| 목표 재고 미확인 | 735 | 729 |
| 목표 양수 추천 / 전체 요청 | 91.8108% | 95.7702% |
| 평균 추가 직선거리 | 기준 | 78.0842m |

전체 요청당 0대 추천률은 6.7340%에서 2.7778%로, 절대 3.9562%p·상대 **58.75% 감소**했습니다. AI 미확인 729건을 모두 실패, NP 미확인을 모두 비실패로 두면 집계 내 감소 민감도 하한은 **53.0547%**입니다. 통계적 신뢰구간이 아닙니다.

E_serving은 이번 아카이브에서 **C/null만 사용**했습니다. 고급 모델이나 실제 이용자 대여 효과·실수신 5분 신선도 검증을 입증한 결과가 아닙니다. 이 지표를 핵심으로 강조한 것은 최종 결과 확인 후의 사후 해석입니다. 새 사전등록 주지표나 기존 F1 목표 달성으로 바꾸어 소개하지 않습니다. 추천 감소율의 블록 신뢰구간은 아직 계산하지 않았습니다.

## 선정 예측기 자체의 조건부 native 평가

| 모델 | h1 F1 | h2 F1 | h3 F1 | 단순 평균 |
| --- | ---: | ---: | ---: | ---: |
| 기존 강한 F | 76.8147% | 69.8261% | 65.8134% | 70.8180% |
| P53/P51/P48 | 77.4090% | 70.9553% | 66.8916% | 71.7520% |

평균 차이 +0.93394%p, 목표 날짜 7일 paired 95% CI +0.81961~+1.04181%p입니다. 이는 추천 감소율의 CI가 아닙니다. **평균 F1 +5%p 도전 목표는 미달**입니다. 현재 양수 신규 고갈 재현율은 +3.6709/+4.5379/+3.3897%p 개선됐으나 현재 양수 FP는 8,011/9,281/6,378건 늘고 현재 0대 TP는 4,468/4,748/2,079건 줄었습니다.

예측 유효 분모는 h1 12,179,629 / h2 12,176,686 / h3 12,173,743행입니다. E_native 추천은 0대 3,924건(69.34375% 감소)이지만 보류 2,769건으로 738건 늘어 주 비교로 사용하지 않습니다. 목표 양수 추천은 S보다 418건 적습니다.

## 실제 데이터

- 서울 공공자전거 공개 과거 재고 파일: 2022~2024 학습. 2023 무표제 첫 행 보존, 결측과 실제 0대 분리.
- 공식 대여소 좌표/목록 파일과 API 카탈로그: 역사상 번호·서비스 ID·적용 기간, 주변 특징. 현재 신원 재검증 필요.
- 기상청 과거 포털 예보 ZIP과 API 대조: 고급 모델의 목표 시각 입력. 같은 숫자 아카이브 검증과 live 물리 단위·RN1 호환 검증을 구분.
- C는 대여소 코드·현재 재고·log 재고·시각·요일·월·주말·h의 8열이며 기상이나 공휴일 API를 사용하지 않음.
- 대기질·버스·열차·관광은 접근 확인과 실제 채택을 구별. NEIS/SGIS/DEM 제외.

2025년 1~2월 보정, 3~4월 모델/정책 선택, 5~6월 기존 개발 확인, 동결 후 7~12월 최종 아카이브 평가를 사용했습니다. 새 학습·보정·정책 선택·H2 재실행을 하지 않았습니다.
